# Главная объединяет описание сервиса и выбор типа встречи

В сервисе один заранее заданный владелец календаря, а путь гостя начинается с выбора типа встречи. Главная страница содержит описание сервиса и карточки типов встреч с переходом к записи: это позволяет выбрать формат встречи без отдельной промежуточной страницы каталога.

На этапе первой функции страница записи является заглушкой, сохраняющей контекст выбранного типа встречи и позволяющей вернуться на главную. Календарь свободного времени, создание записи и управление встречами относятся к следующему этапу; их правила будут уточнены отдельно. Такое разделение соответствует шагу 4 курса и позволяет проверить завершённый переход с главной, прежде чем реализовывать бронирование.
