# Первая функция: главная страница

Согласовано в интервью по шагу 4 курса «Календарь звонков».

## Содержание

Главная предназначена для гостя, который выбирает формат встречи с единственным владельцем календаря. Имя и биография владельца на этом этапе не показываются.

- Заголовок: «Календарь звонков».
- Описание: «Выберите формат встречи и удобное время. Регистрация не нужна».
- Тип встречи «Знакомство»: 15 минут, «Короткий звонок, чтобы обсудить ваш вопрос».
- Тип встречи «Консультация»: 30 минут, «Подробный разговор по вашей задаче».
- На каждой карточке ссылка «Выбрать время», ведущая к записи на соответствующий тип встречи.

Два типа встречи заранее заданы. Управление типами встреч относится к следующему этапу.

## Страница записи

Пока это заглушка. Она показывает название и длительность выбранного типа встречи, сообщение «Онлайн-запись скоро появится» и ссылку «Вернуться на главную». Создание записи пока недоступно.

## Оформление

Светлый интерфейс, белые карточки, синий акцент и крупные читаемые заголовки. На телефоне карточки располагаются в одну колонку. Навигация доступна с клавиатуры, фокус виден.

## Проверки

Проверить через интерфейс приложения: содержание главной, переход от каждой карточки к заглушке с правильным типом встречи и возврат на главную. Прямое открытие ссылки записи должно сохранять выбор типа встречи. Неизвестный тип встречи должен давать понятное сообщение и возможность вернуться.

Общая команда проверок — `mise run check`. Для завершения шага требуется успешный прогон GitHub Actions.

## За пределами этапа

Календарь свободного времени, форма гостя, создание записи, управление типами встреч и список встреч владельца. Часовой пояс, расписание и правила доступных стартов будут согласованы на следующем этапе.
