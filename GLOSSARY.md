# Календарь звонков

Сервис записи на встречи с одним заранее заданным владельцем календаря.

## Термины

**Владелец календаря**:
Человек, к которому записываются на встречи. Владелец задаёт типы встреч и просматривает предстоящие встречи.
_Избегать_: администратор, организатор.

**Гость**:
Человек, который выбирает тип встречи и записывается на свободное время без регистрации.
_Избегать_: клиент, зарегистрированный пользователь.

**Тип встречи**:
Формат встречи с названием, описанием и длительностью. Гость выбирает тип встречи перед выбором времени.
_Избегать_: услуга, тариф, категория звонка.

**Слот**:
Интервал времени, доступный для записи на выбранный тип встречи. Его длительность совпадает с длительностью этого типа встречи.
_Избегать_: дата встречи, свободный день.

**Запись на встречу**:
Подтверждённая договорённость о встрече гостя с владельцем календаря в определённое время.
_Избегать_: заказ, заявка.

**Рабочие часы**:
Интервал времени суток, в который владелец календаря принимает встречи; за его пределами слоты не формируются.
_Избегать_: расписание, график работы.

**Окно записи**:
Набор ближайших календарных дней, в пределах которого гость может выбрать слот; сдвигается вместе с текущей датой.
_Избегать_: горизонт, период бронирования, диапазон дат.

**Шаг стартов**:
Интервал между соседними возможными временами начала слотов внутри рабочих часов.
_Избегать_: сетка времени, частота слотов.

**Конфликт**:
Ситуация, когда запрашиваемое время брони пересекается с уже существующей записью на встречу; гость получает понятное сообщение и выбирает другое время.
_Избегать_: коллизия, двойное бронирование, ошибка занятости.
